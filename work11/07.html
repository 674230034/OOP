เรื่อง Order และคำนวณยอดรวมด้วย DiscountPolicy (บริบท: ร้านสวัสดิการนักศึกษา/ร้านชมรม รองรับส่วนลดนักศึกษา)
รายวิชา การเขียนโปรแกรมเชิงวัตถุ (PHP 8.4+)

ชื่อ-นามสกุล:
รหัสนักศึกษา:
ชั้นปี/ห้อง:
คะแนน: /50

คำชี้แจง: ให้นักศึกษาศึกษา Class Diagram ด้านล่าง แล้วทำกิจกรรมทุกส่วนให้ครบถ้วน

จุดประสงค์การเรียนรู้:

  • อธิบาย Composition over Inheritance จากความสัมพันธ์ Order–OrderItem ได้
  • ใช้ Strategy Pattern แยกนโยบายส่วนลดออกจาก Order ได้
  • อธิบาย GRASP: Information Expert และ Creator จากแผนภาพได้
  • คำนวณยอดรวม/ยอดสุทธิ และทดสอบกรณีผิดพลาดได้ถูกต้อง

Order ใช้ Composition ในการรวม OrderItem และใช้ Strategy เพื่อเปิดรับนโยบายส่วนลดใหม่ในอนาคต

ส่วนที่ 1: อ่านแผนภาพแล้วตอบคำถาม (10 คะแนน)

1) สัญลักษณ์สี่เหลี่ยมทึบ (filled diamond) ด้าน Order ของความสัมพันธ์กับ OrderItem หมายถึงอะไร แตกต่างจาก Aggregation อย่างไร 2 คะแนน

2) OrderItem ถูกกำกับว่า «InformationExpert» หมายความว่าอย่างไร และสอดคล้องกับเมธอดใดในคลาส 2 คะแนน

3) ลูกศร “DIP / Strategy” จาก Order ชี้ไปยัง DiscountPolicy สื่อความหมายว่าอย่างไร 2 คะแนน

4) ป้าย “OCP” บนลูกศรจาก PercentageDiscount ไปยัง DiscountPolicy หมายถึงอะไร หากเพิ่มส่วนลดแบบจำนวนเงินคงที่ (FixedDiscount) ต้องแก้โค้ดส่วนใดบ้าง 2 คะแนน

5) ลูกศร “Validation” จาก OrderItem และ PercentageDiscount ชี้ไปยัง InvalidArgumentException แต่ละคลาสตรวจสอบเงื่อนไขใดบ้าง 1 คะแนน

6) เมธอด subtotal() และ total() ของ Order แตกต่างกันอย่างไร 1 คะแนน

ส่วนที่ 2: วิเคราะห์โค้ด (10 คะแนน)

พิจารณาโค้ดต่อไปนี้ แล้วตอบคำถาม

<?php declare(strict_types=1);

final readonly class OrderItem
{
    public function __construct(
        public string $name,
        public int $quantity,
        public float $unitPrice,
    ) {
        if (trim($name) === '') {
            throw new InvalidArgumentException('Item name cannot be empty.');
        }

        if ($quantity <= 0 || $unitPrice < 0.0) {
            throw new InvalidArgumentException('Invalid order item.');
        }
    }

    public function total(): float
    {
        return $this->quantity * $this->unitPrice;
    }
}

interface DiscountPolicy
{
    public function discount(float $subtotal): float;
}

final class PercentageDiscount implements DiscountPolicy
{
    public function __construct(private readonly float $percent)
    {
        if ($percent < 0.0 || $percent > 100.0) {
            throw new InvalidArgumentException('Percent must be between 0 and 100.');
        }
    }

    public function discount(float $subtotal): float
    {
        return $subtotal * $this->percent / 100.0;
    }
}

final class Order
{
    /** @param list<OrderItem> $items */
    public function __construct(
        private readonly array $items,
        private readonly DiscountPolicy $discountPolicy,
    ) {}

    public function subtotal(): float
    {
        return array_sum(array_map(
            static fn (OrderItem $item): float => $item->total(),
            $this->items,
        ));
    }

    public function total(): float
    {
        $subtotal = $this->subtotal();

        return round($subtotal - $this->discountPolicy->discount($subtotal), 2);
    }
}

$studentOrder = new Order(
    [
        new OrderItem('ข้าวผัด', 2, 60.00),
        new OrderItem('น้ำดื่ม', 2, 10.00),
    ],
    new PercentageDiscount(10.00),
);

echo sprintf('ยอดสุทธิร้านสวัสดิการนักศึกษา: %.2f บาท', $studentOrder->total());

1) โค้ดบรรทัดใดแสดงให้เห็นว่า Order “ไม่รู้รายละเอียด” ของนโยบายส่วนลด จงอธิบาย 2 คะแนน

2) จงคำนวณยอดสุทธิของคำสั่งซื้อในโค้ด (ข้าวผัด 2 × 60, น้ำดื่ม 2 × 10, ส่วนลด 10%) พร้อมแสดงวิธีทำ 3 คะแนน

3) การสร้าง new OrderItem('', 1, 50) และ new OrderItem('ปากกา', 0, 20) จะเกิดอะไรขึ้นแต่ละกรณี เพราะเหตุใด 3 คะแนน

4) เหตุใด OrderItem จึงเป็น final readonly class การออกแบบนี้ดีต่อระบบคำสั่งซื้ออย่างไร 2 คะแนน

ส่วนที่ 5: สะท้อนคิดเชิงออกแบบ OOAD (6 คะแนน)

1) การใช้ Composition แทน Inheritance ในการประกอบ Order จาก OrderItem มีข้อดีอย่างไร จงยกตัวอย่างสถานการณ์ที่ Inheritance จะทำให้การออกแบบแย่ลง 2 คะแนน

2) ระบบนี้สอดคล้องกับ OCP อย่างไร หากร้านสวัสดิการเพิ่มโปรโมชัน “ซื้อครบ 300 บาท ลดเพิ่ม 20 บาท” นักศึกษาจะออกแบบคลาสใหม่อย่างไร 2 คะแนน

3) เหตุใดการให้ OrderItem รับผิดชอบเมธอด total() จึงถูกต้องตามหลัก Information Expert 2 คะแนน
