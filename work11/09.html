เรื่อง แก้ Trait Conflict และสร้าง Audit Log สำหรับเอกสารทะเบียนนักศึกษา (บริบท: ใบสมัครชมรม ใบเปลี่ยนคำนำหน้า หรือเอกสารขอใช้สถานที่)

คำชี้แจง: ให้นักศึกษาศึกษา Class Diagram ด้านล่าง แล้วทำกิจกรรมทุกส่วนให้ครบถ้วน

จุดประสงค์การเรียนรู้:

  • อธิบายความแตกต่างของ Trait กับ Class และ Interface ได้
  • แก้เมธอดชนกันระหว่าง Trait ด้วย insteadof และ as ได้
  • อธิบายหลัก DRY และ Separation of Concerns จากการใช้ Trait ได้
  • ทดสอบผลลัพธ์ของ createdAt, auditTimestamp และ auditLog ได้ถูกต้อง

แผนภาพอ้างอิง

Trait ช่วย reuse พฤติกรรมข้ามคลาสได้ แต่เมื่อเมธอดชนกันต้องระบุแหล่งที่มาหลักและ alias อย่างชัดเจน

ส่วนที่ 1: อ่านแผนภาพแล้วตอบคำถาม (10 คะแนน)

1) «trait» คืออะไร แตกต่างจาก class และ interface อย่างไร 2 คะแนน

2) หากคลาส Document ใช้ Timestampable และ Auditable โดยไม่ระบุกฎแก้ conflict จะเกิดอะไรขึ้น 2 คะแนน

3) คำสั่ง Timestampable::timestamp insteadof Auditable มีความหมายว่าอย่างไร 2 คะแนน

4) คำสั่ง Auditable::timestamp as auditTimestamp ทำหน้าที่อะไร และเหตุใดจึงจำเป็นในกรณีนี้ 2 คะแนน

5) หลังแก้ conflict แล้ว Document มีเมธอดใดให้ใช้งานบ้าง จง liệt kê ตามแผนภาพ 1 คะแนน

6) การใช้ Trait ในข้อนี้สอดคล้องกับหลัก DRY และ Separation of Concerns อย่างไร 1 คะแนน

ส่วนที่ 2: วิเคราะห์โค้ด (10 คะแนน)

พิจารณาโค้ดต่อไปนี้ แล้วตอบคำถาม

<?php declare(strict_types=1);

trait Timestampable
{
    public function timestamp(): string
    {
        return 'Created: ' . date('c');
    }
}

trait Auditable
{
    public function timestamp(): string
    {
        return 'Audited: ' . date('c');
    }

    public function auditMessage(): string
    {
        return 'Student document was audited.';
    }
}

final class Document
{
    use Timestampable, Auditable {
        Timestampable::timestamp insteadof Auditable;
        Auditable::timestamp as auditTimestamp;
    }

    public function createdAt(): string
    {
        return $this->timestamp();
    }

    public function auditLog(): string
    {
        return sprintf('%s | %s', $this->auditTimestamp(), $this->auditMessage());
    }
}

$doc = new Document();

echo $doc->createdAt(), PHP_EOL;
echo $doc->auditLog(), PHP_EOL;

1) การเรียก $doc->createdAt() ให้ผลลัพธ์ขึ้นต้นด้วยคำว่าอะไร เพราะใช้ timestamp() ของ Trait ใด 3 คะแนน

2) การเรียก $doc->auditTimestamp() ให้ผลลัพธ์ขึ้นต้นด้วยคำว่าอะไร ทั้งที่ไม่ได้ประกาศเมธอดนี้ไว้ใน Document โดยตรง 3 คะแนน

3) หากคงคำสั่ง as ไว้แต่ลบ insteadof ออก จะเกิดอะไรขึ้น เพราะเหตุใด 2 คะแนน

4) เหตุใดจึงไม่ควรใช้ Trait พร่ำเพรื่อจนพฤติกรรมของคลาสกระจัดกระจาย จงอธิบายด้วยหลัก Separation of Concerns 2 คะแนน
