คำชี้แจง: ให้นักศึกษาศึกษา Class Diagram ด้านล่าง แล้วทำกิจกรรมทุกส่วนให้ครบถ้วน

จุดประสงค์การเรียนรู้:

  • อธิบายบทบาท Use Case Controller และ GRASP Creator จากแผนภาพได้
  • ใช้ Dependency Injection เพื่อให้ Service พึ่งพา Abstraction ได้
  • อธิบายหลัก Security by Design ในการจัดการรหัสผ่านได้
  • เขียนแนวทาง Unit Test อย่างน้อย 2 กรณีโดยใช้ Fake/Mock ได้

RegisterUserService ทำหน้าที่เป็น Use Case Controller ไม่ควรรับผิดชอบการ hash เอง หรือสร้าง Repository เอง แต่ควรพึ่งพา abstraction ผ่าน Dependency Injection
ในระบบจริงควรแยก PasswordHash ไปไว้ใน Credential Entity หรือตารางที่ออกแบบมาเพื่อข้อมูลความลับโดยเฉพาะ

ส่วนที่ 1: อ่านแผนภาพแล้วตอบคำถาม (10 คะแนน)

1) RegisterUserService ถูกกำกับว่า «Controller» (Use Case Controller) หมายความว่าอย่างไร 2 คะแนน

2) ลูกศร “DIP / Injection” จาก RegisterUserService ไปยัง UserRepository และ PasswordHasher หมายถึงอะไร และเหตุใด Service จึงไม่ควรสร้าง Repository เอง 2 คะแนน

3) Email «ValueObject» มีบทบาทอย่างไรใน Use Case นี้ (ป้าย Validation / VO) 2 คะแนน

4) ลูกศร “Guard” ชี้ไปยัง InvalidArgumentException หมายถึงการป้องกันกรณีใดบ้าง 1 คะแนน

5) ArgonPasswordHasher ถูกกำกับว่า «Strategy» และลูกศรไปยัง PasswordHasher มีป้าย “OCP” หมายความว่าอย่างไร 2 คะแนน

6) ป้าย “Creator” บนลูกศรจาก RegisterUserService ไปยัง User หมายถึงอะไรตามหลัก GRASP 1 คะแนน

ส่วนที่ 2: วิเคราะห์โค้ด (10 คะแนน)

พิจารณาโค้ดต่อไปนี้ แล้วตอบคำถาม

<?php declare(strict_types=1);

final readonly class User
{
    public function __construct(
        public int $id,
        public string $email,
        public string $passwordHash,
    ) {}
}

interface UserRepository
{
    public function save(User $user): void;
    public function findById(int $id): ?User;
    public function all(): array;
}

final class InMemoryUserRepository implements UserRepository
{
    private array $users = [];
    public function save(User $user): void { $this->users[$user->id] = $user; }
    public function findById(int $id): ?User { return $this->users[$id] ?? null; }
    public function all(): array { return array_values($this->users); }
}

final readonly class Email
{
    private function __construct(public string $value) {}

    public static function fromString(string $value): self
    {
        $normalized = strtolower(trim($value));
        if (filter_var($normalized, FILTER_VALIDATE_EMAIL) === false) {
            throw new InvalidArgumentException('Invalid email address.');
        }
        return new self($normalized);
    }

    public function toString(): string { return $this->value; }
}

interface PasswordHasher
{
    public function hash(string $plainText): string;
}

final class ArgonPasswordHasher implements PasswordHasher
{
    public function hash(string $plainText): string
    {
        return password_hash($plainText, PASSWORD_DEFAULT);
    }
}

final class RegisterUserService
{
    public function __construct(
        private readonly UserRepository $users,
        private readonly PasswordHasher $hasher,
    ) {}

    public function register(int $id, string $email, string $password): User
    {
        $userEmail = Email::fromString($email);

        if (strlen($password) < 12) {
            throw new InvalidArgumentException('Password must be at least 12 characters.');
        }

        if ($this->users->findById($id) !== null) {
            throw new InvalidArgumentException('Student ID already exists.');
        }

        $passwordHash = $this->hasher->hash($password);
        $user = new User($id, $userEmail->toString(), $passwordHash);
        $this->users->save($user);

        return $user;
    }
}

$repo = new InMemoryUserRepository();
$service = new RegisterUserService($repo, new ArgonPasswordHasher());

$user = $service->register(680001, 'student@example.ac.th', 'StudentPass123!');
var_dump(password_verify('StudentPass123!', $user->passwordHash));

1) โค้ดส่วนใดแสดงให้เห็นว่าระบบไม่เก็บรหัสผ่านแบบ Plain Text จงอธิบาย 3 คะแนน

2) การเรียก register(680002, 'invalid-email', 'StudentPass123!') จะเกิดอะไรขึ้น และข้อมูลจะถูกบันทึกหรือไม่ 2 คะแนน

3) การเรียก register(680003, 'valid@example.ac.th', 'short') จะเกิดอะไรขึ้น เหตุใดจึงกำหนดความยาวขั้นต่ำ 12 ตัวอักษร 2 คะแนน

4) การที่ Service รับ UserRepository เป็น Interface ช่วยให้การเขียน Unit Test ง่ายขึ้นอย่างไร 3 คะแนน
