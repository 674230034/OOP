ส่วนที่ 1: อ่านแผนภาพแล้วตอบคำถาม (10 คะแนน)

1) Stereotype «Encapsulation» ที่กำกับคลาส Product สื่อความหมายว่าอย่างไร 2 คะแนน

ตรวจสอบราคาสินค้าว่าถูกต้องหรือไม่

2) สัญลักษณ์ + และ - หน้าสมาชิกของคลาส หมายถึงอะไร 2 คะแนน

สัญลักษณ์ + หมายถึง Public และ สัญลักษณ์ - หมายถึง Private

3) property price อ่านได้จากภายนอกแต่แก้ไขโดยตรงไม่ได้ ใน PHP 8.4 ใช้กลไกใด และเหตุใดจึงออกแบบเช่นนั้น 2 คะแนน

ใช้กลไก Property Hooks (เฉพาะ get hook ไม่มี set) หรือการใช้ Asymmetric Visibility ด้วยสัญลักษณ์ public private(set)

4) จงระบุ Invariant ของคลาส Product มา 2 ข้อ 2 คะแนน

1. id ต้องเป็นค่าบวก 2. price ต้องไม่ติดลบ

5) ลูกศรที่กำกับว่า “Invariant Guard” ชี้ไปยัง InvalidArgumentException หมายความว่าอย่างไร 1 คะแนน

กลไกการตรวจสอบความถูกต้องของข้อมูลนำเข้า

6) เพราะเหตุใด Product จึงถือเป็น “Information Expert” ในการคำนวณราคาหลังลด 1 คะแนน

เพราะเป็นผู้เก็บข้อมูลที่จำเป็นในการใช้ เช่น ราคาตั้งต้น (Price)

ส่วนที่ 2: วิเคราะห์โค้ด (10 คะแนน)

พิจารณาโค้ดต่อไปนี้ แล้วตอบคำถาม

<?php declare(strict_types=1);

final class Product
{
    public private(set) float $price;

    public function __construct(
        public readonly int $id,
        public readonly string $name,
        float $price,
    ) {
        $this->price = $this->validatePrice($price);
    }

    public function applyDiscount(float $percent): void
    {
        if ($percent < 0.0 || $percent > 100.0) {
            throw new InvalidArgumentException('Discount must be between 0 and 100.');
        }

        $this->price = round($this->price * (100.0 - $percent) / 100.0, 2);
    }

    public function displayPrice(): string
    {
        return sprintf('%s (#%d) ราคา: %.2f บาท', $this->name, $this->id, $this->price);
    }

    private function validatePrice(float $price): float
    {
        if ($price < 0.0) {
            throw new InvalidArgumentException('Price cannot be negative.');
        }

        return round($price, 2);
    }
}

1) บรรทัดใดป้องกันไม่ให้สร้างสินค้าที่มีราคาติดลบ 2 คะแนน

if ($price < 0.0) { throw new InvalidArgumentException('Price cannot be negative.'); }

2) เมื่อเรียก new Product(1, 'สมุดโน้ต', 45.00) แล้วเรียก applyDiscount(10) ค่า price จะเป็นเท่าใด จงแสดงวิธีทำ 3 คะแนน

1. คำนวณส่วนลด 45.00 × (10 / 100) = 4.50 2. นำส่วนลดไปหักจากราคาเดิม 45.00 - 4.50 = 40.50 ดังนั้น price = 40.50 บาท

3) หากเรียก applyDiscount(150) จะเกิดอะไรขึ้น เพราะโค้ดบรรทัดใด 3 คะแนน

จะเกิด InvalidArgumentException เพราะส่วนลดต้องอยู่ระหว่าง 0–100% แต่ 150 มากกว่า 100 โค้ดที่ใช้ if ($percent < 0.0 || $percent > 100.0) { throw new InvalidArgumentException( 'Discount must be between 0 and 100.' ); }

4) หากภายนอกคลาสเขียนว่า $product->price = -500; จะเกิดผลใด เพราะเหตุใด 2 คะแนน

จะเกิด Error เพราะไม่สามารถกำหนดค่าให้ $price จากภายนอกคลาสได้

ส่วนที่ 5: สะท้อนคิดเชิงออกแบบ OOAD (6 คะแนน)

1) คลาส Product แสดงถึง Single Responsibility Principle อย่างไร 2 คะแนน

คลาส Product มีหน้าที่จัดการข้อมูลสินค้า เช่น เก็บชื่อ รหัส ราคา ตรวจสอบราคา คำนวณส่วนลด และแสดงราคาสินค้า จึงมีความ
รับผิดชอบหลักที่เกี่ยวข้องกับ Product โดยตรง

2) Information Hiding ปรากฏอยู่ในจุดใดของคลาสนี้บ้าง จงยกตัวอย่างอย่างน้อย 2 จุด 2 คะแนน

ตัวแปร $price เป็น private ทำให้ภายนอกคลาสไม่สามารถแก้ไขราคาโดยตรงได้
เมธอด validatePrice() เป็น private ทำให้รายละเอียดการตรวจสอบราคาถูกซ่อนไว้ภายในคลาส

3) หากต้องการเพิ่มโปรโมชัน “ซื้อครบ 500 บาท ลดเพิ่ม 5%” นักศึกษาจะออกแบบเพิ่มเติมอย่างไร โดยไม่ทำลาย invariant เดิม 2 คะแนน

เพิ่มเมธอดใหม่ applyPromotion() สำหรับตรวจสอบว่าราคาครบ 500 บาทหรือไม่ แล้วเรียก applyDiscount(5) เพื่อคำนวณ
ส่วนลดโดยไม่แก้ไข validatePrice() และยังคงกำหนดให้ราคาไม่ติดลบเหมือนเดิม
