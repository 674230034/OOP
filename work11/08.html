เรื่อง ระบบแจ้งเตือนตารางเรียน/การบ้านหลายช่องทาง (Notifier) (บริบท: ระบบแจ้งเตือนของมหาวิทยาลัยแจ้งนักศึกษาผ่าน Email/SMS/Line)
รายวิชา การเขียนโปรแกรมเชิงวัตถุ (PHP 8.4+)

ชื่อ-นามสกุล:
รหัสนักศึกษา:
ชั้นปี/ห้อง:
คะแนน: /50

คำชี้แจง: ให้นักศึกษาศึกษา Class Diagram ด้านล่าง แล้วทำกิจกรรมทุกส่วนให้ครบถ้วน

จุดประสงค์การเรียนรู้:

  • ใช้ Interface และ Polymorphism สร้างระบบแจ้งเตือนหลายช่องทางได้
  • อธิบาย DIP, OCP และ Protected Variations จากแผนภาพได้
  • ออกแบบ Notifier ที่เพิ่มช่องทางใหม่ได้โดยไม่ต้องแก้โค้ดเดิม
  • เขียน Test Case อย่างน้อย 2 กรณีตามข้อกำหนดได้

Notifier ไม่ควรตรวจชนิดของ Channel ด้วย instanceof เพราะจะผิดต่อ Polymorphism และทำให้ระบบปิดรับการขยาย

ส่วนที่ 1: อ่านแผนภาพแล้วตอบคำถาม (10 คะแนน)

1) «interface» NotificationChannel ที่มีเมธอด +send(recipient, message) : void ทำหน้าที่อะไรในระบบ 2 คะแนน

2) EmailChannel และ SmsChannel ถูกกำกับว่า «Strategy» หมายความว่าอย่างไร หากต้องการเพิ่ม LineChannel ต้องทำอย่างไร 2 คะแนน

3) ลูกศร “Polymorphism / DIP” จาก Notifier ชี้ไปยัง NotificationChannel สื่อความหมายว่าอย่างไร 2 คะแนน

4) Notifier เก็บ channels เป็น -iterable channels การรองรับหลายช่องทางพร้อมกันดีกว่าการรับช่องเดียวอย่างไร และสอดคล้องกับหลักการใด 2 คะแนน

5) ลูกศร “Validation” ชี้ไปยัง InvalidArgumentException หมายถึงการตรวจสอบใด และเกิดขึ้นเมื่อใด 1 คะแนน

6) เหตุใด Notifier จึงห้ามตรวจสอบชนิดของ Channel ด้วย instanceof 1 คะแนน

ส่วนที่ 2: วิเคราะห์โค้ด (10 คะแนน)

พิจารณาโค้ดต่อไปนี้ แล้วตอบคำถาม

<?php declare(strict_types=1);

interface NotificationChannel
{
    public function send(string $recipient, string $message): void;
}

final class EmailChannel implements NotificationChannel
{
    public function send(string $recipient, string $message): void
    {
        echo sprintf("[Email] ถึง: %s | ข้อความ: %s\n", $recipient, $message);
    }
}

final class SmsChannel implements NotificationChannel
{
    public function send(string $recipient, string $message): void
    {
        echo sprintf("[SMS] ถึง: %s | ข้อความ: %s\n", $recipient, $message);
    }
}

final class Notifier
{
    /** @param iterable<NotificationChannel> $channels */
    public function __construct(private readonly iterable $channels) {}

    public function notify(string $recipient, string $message): void
    {
        if (trim($message) === '') {
            throw new InvalidArgumentException('Message cannot be empty.');
        }

        foreach ($this->channels as $channel) {
            $channel->send($recipient, $message);
        }
    }
}

$notifier = new Notifier([
    new EmailChannel(),
    new SmsChannel(),
]);

// Test case 1: ส่งข้อความสำเร็จ
$notifier->notify('student@example.ac.th', 'มีการบ้าน PHP กำหนดส่งวันศุกร์นี้');

// Test case 2: ข้อความว่างต้องถูกปฏิเสธ
try {
    $notifier->notify('student@example.ac.th', '   ');
} catch (InvalidArgumentException $e) {
    echo 'Expected error: ', $e->getMessage(), PHP_EOL;
}

1) โค้ดบรรทัดใดแสดงให้เห็นว่า Notifier ไม่ผูกติดกับ concrete channel จงอธิบาย 2 คะแนน

2) เมื่อเรียก notify ใน Test case 1 ผลลัพธ์ที่แสดงบนหน้าจอคืออะไรบ้าง 3 คะแนน

3) การเรียก notify ด้วยข้อความ ' ' จะเกิดอะไรขึ้น และเหตุใดจึงใช้ trim() ในการตรวจสอบ 2 คะแนน

4) หาก Notifier ใช้ if ($channel instanceof EmailChannel) เพื่อเลือกวิธีส่ง จะผิดหลักการใด และส่งผลเสียอย่างไร 3 คะแนน

ส่วนที่ 5: สะท้อนคิดเชิงออกแบบ OOAD (6 คะแนน)

1) ระบบนี้สอดคล้องกับ Open/Closed Principle อย่างไร จงยกตัวอย่างการเพิ่มช่องทางใหม่ 2 คะแนน

2) “จุดที่เปลี่ยนแปลง” ในข้อนี้คืออะไร และการออกแบบนี้ปกป้อง Notifier ด้วย Protected Variations อย่างไร 2 คะแนน

3) การใช้ iterable ร่วมกับ foreach และเรียก send() ผ่าน interface ดีกว่าการตรวจชนิดของแต่ละ channel อย่างไร จงอธิบายด้วยแนวคิด Polymorphism 2 คะแนน
