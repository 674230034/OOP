ใบงานปฏิบัติการที่ 3

เรื่อง Inheritance / Polymorphism สำหรับคำนวณพื้นที่สื่อประชาสัมพันธ์กิจกรรมนักศึกษา (บริบท: สติกเกอร์วงกลมติดบัตรนักศึกษา และป้ายโปสเตอร์สี่เหลี่ยม)
รายวิชา การเขียนโปรแกรมเชิงวัตถุ (PHP 8.4+)

ชื่อ-นามสกุล:
รหัสนักศึกษา:
ชั้นปี/ห้อง:
คะแนน: /50

คำชี้แจง: ให้นักศึกษาศึกษา Class Diagram ด้านล่าง แล้วทำกิจกรรมทุกส่วนให้ครบถ้วน

จุดประสงค์การเรียนรู้:

  • อธิบายความแตกต่างของ Interface และ Concrete Class จากแผนภาพได้
  • ใช้ Polymorphism เรียกเมธอด area() ผ่าน Shape โดยไม่ต้องตรวจชนิดคลาส
  • อธิบายหลักการ OCP, LSP และ DIP ที่ปรากฏในแผนภาพได้
  • คำนวณพื้นที่และทดสอบกรณีผิดพลาดได้ถูกต้อง

แผนภาพอ้างอิง

Polymorphism OCP LSP DIP

Circle และ Rectangle ต้องแทนที่ Shape ได้อย่างถูกต้องตาม LSP และทำให้โค้ดหลักเปิดรับ extension แต่ปิดรับการแก้ไขตาม OCP

ส่วนที่ 1: อ่านแผนภาพแล้วตอบคำถาม (10 คะแนน)

1) «interface» Shape ที่มีเมธอด +area() : float ทำหน้าที่อะไรในระบบ 2 คะแนน

2) ลูกศรหัวสามเหลี่ยมโปร่งจาก Circle และ Rectangle ชี้ไปยัง Shape หมายถึงความสัมพันธ์แบบใดใน UML 2 คะแนน

3) ป้ายกำกับ “OCP / LSP” บนลูกศร หมายถึงหลักการใด จงอธิบายแต่ละหลักการโดยย่อ 2 คะแนน

4) เหตุใดโค้ดหลักจึงไม่ต้องใช้ if หรือ instanceof ตรวจสอบชนิดของคลาส 2 คะแนน

5) property radius, width, height เป็น private readonly เพื่อประโยชน์ใด 1 คะแนน

6) หากต้องการเพิ่มรูปทรง Triangle ในอนาคต โค้ดส่วนใดต้องแก้ไขบ้าง 1 คะแนน

ส่วนที่ 2: วิเคราะห์โค้ด (10 คะแนน)

พิจารณาโค้ดต่อไปนี้ แล้วตอบคำถาม

<?php declare(strict_types=1);

interface Shape
{
    public function area(): float;
}

final class Circle implements Shape
{
    public function __construct(private readonly float $radius)
    {
        if ($radius < 0.0) {
            throw new InvalidArgumentException('Radius cannot be negative.');
        }
    }

    public function area(): float
    {
        return M_PI * $this->radius ** 2;
    }
}

final class Rectangle implements Shape
{
    public function __construct(
        private readonly float $width,
        private readonly float $height,
    ) {
        if ($width < 0.0 || $height < 0.0) {
            throw new InvalidArgumentException('Width and height cannot be negative.');
        }
    }

    public function area(): float
    {
        return $this->width * $this->height;
    }
}

$promotionMedia = [
    new Circle(0.10),          // สติกเกอร์วงกลมติดบัตรนักศึกษา
    new Rectangle(1.20, 0.80), // ป้ายโปสเตอร์กิจกรรม
];

$totalArea = array_sum(array_map(
    static fn (Shape $shape): float => $shape->area(),
    $promotionMedia,
));

echo sprintf('พื้นที่สื่อประชาสัมพันธ์รวม: %.2f ตารางเมตร', $totalArea);

1) บรรทัดใดในโค้ดหลักที่แสดง Polymorphism จงอธิบายการทำงาน 3 คะแนน

2) จงคำนวณพื้นที่ของ Circle รัศมี 0.10 และ Rectangle ขนาด 1.20 × 0.80 แล้วหาพื้นที่รวม (แสดงวิธีทำ) 3 คะแนน

3) การเรียก new Circle(-5) จะเกิดอะไรขึ้น และเหตุใดจึงต้องตรวจสอบค่าใน constructor 2 คะแนน

4) หากลบ implements Shape ออกจาก Circle จะเกิดผลใดกับโค้ดหลัก เพราะเหตุใด 2 คะแนน

ส่วนที่ 5: สะท้อนคิดเชิงออกแบบ OOAD (6 คะแนน)

1) ระบบนี้สอดคล้องกับ Open/Closed Principle อย่างไร หากเพิ่ม Triangle โค้ดหลักต้องแก้ไขหรือไม่ 2 คะแนน

2) Circle และ Rectangle สอดคล้องกับ Liskov Substitution Principle อย่างไร 2 คะแนน

3) Dependency Inversion Principle ปรากฏในโค้ดหลักจุดใด จงอธิบาย 2 คะแนน
